# 预注册：loop_L 质量 A/B（固定 L=1 vs 随机 L） · 2026-10-06

## 0. 一句话
把"随机循环轮数"这个训练正则去掉，能省 **32.8%** 步时；本实验回答：
去掉它，质量会不会塌（尤其是推理期弹性选 L=2/3 的能力）。

## 1. 速度侧（已实测：交流电、threads=6、真模型 fwd+bwd）
| loop_L | 秒/步 | 相对 L=1 | 理论 pass 比 |
|---|---|---|---|
| 1 | **2.508** | 1.00× | 1.00× |
| 2 | 3.613 | 1.44× | 1.40× |
| 3 | 5.073 | **2.02×** | 1.80× |

随机 L~U{1..3} 均值 ≈ 3.73s/步 ⇒ **固定 L=1 = −32.8%**；
偏斜 80/0/20 ⇒ −19.0%；偏斜 75/0/25 ⇒ −15.6%。
（pass 数模型：6+4L = 10/14/18；深循环比理论更贵，每轮多 ~0.5% 系数的碎操作。）

## 2. 假设
- H1：随机 L 是必要的 —— 去掉后 L=2/3 推理质量显著低于对照（弹性选 L 的杠杆丢失）。
- H0：可替代 —— 3000 步再加热微调里去掉它，val 与各 L 采样质量都不塌。

## 3. 设计（代码：今日新增 `--loop_p`，只改采样分布，不动架构）
- 起点：`i5build/loop_ar4/ckpt.pt/ckpt_24000.pt`（全局步 24000）。
- 两臂（同 ckpt / seed / LR / 数据 / 供给，仅 L 分布不同）：
  - **Arm-L1**：`--loop_p 1,0,0`（循环模块按 L_max=3 挂载以保证权重完整加载，采样恒 1）
  - **Arm-Random**：均匀 L~U{1..3}（对照组）
- ~3000 步（目标全局 27000）；`--lr 3e-5 --lr-min 3e-5` 恒 LR 再加热微调；
  `--val_frac 0.02 --val_every 500`；`--threads 6`；`--seed 1234`；交流电。
- 运行脚本：`i5build/run_loop_ab.ps1`（顺序两臂；日志 `i5build/loop_ab_*/train.log`；`.done` = 完成标记）。

## 4. 判据（跑之前定死）
1. **数字**：val loss 曲线（22500→27000，6 点）。Δ = val(L1) − val(Random) @ 27000。
   - ✅ Δ ≤ +0.01；⚠️ +0.01 < Δ ≤ +0.03；❌ Δ > +0.03
2. **采样（人眼为主）**：两臂最终 ckpt 各在 L=1/2/3 上采样：
   `python sample_ar.py --ar <ckpt> --vqvae <vk> --loop_L {1,2,3} --loop-cache perloop --seed 0 --n 16`
   （同一组真实前缀）；并排看板。关键：Arm-L1 的 L=2/3 是否明显塌、L=1 是否至少不差。
3. **决策规则**：
   - Δ≤0.01 且 L=1 不差 且 L=2/3 不塌 → **采用固定 L=1（训练 −33%）**
   - L=1 不差、L=2/3 明显塌 → **采用偏斜课程 0.8/0/0.2（−19%）**
   - L=1 也变差 或 Δ>0.03 → 维持随机 L
4. **边界声明**：3000 步恒 LR 属"再加热微调"口径，不能外推到从零训练；
   本实验只回答"能否安全去掉随机 L"。

## 5. 成本与产物
- 时长：≈ 2.4h（L1）+ 3.5h（Random）≈ **6h**
- 产物：两臂 ckpt（每 1000 步 + last）、val 曲线、`loop_ab_driver.log`、采样看板
