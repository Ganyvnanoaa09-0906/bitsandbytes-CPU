# 2bit 判决:真实扩散模型上不成立

## 结论

在 **SD1.5 完整 pipeline** 上做端到端出图对比,同一 prompt、同 seed、同 20 步:

| 格式 | 量化存储 | 图像 |
|---|---|---|
| fp32 | — | 宇航员,正常 |
| **4bit NF4** | 139.5 MB | **宇航员,视觉几乎一致** |
| **2bit 均匀** | 84.4 MB(60.5%) | **纯噪声,完全崩坏** |

**2bit 在这条路上不成立。** 省 39.5% 存储,代价是图彻底坏掉。

## 更重要的:像素误差这个判据是无效的

```
4bit vs fp32  像素 rel 0.3153   →  视觉几乎相同
2bit vs fp32  像素 rel 0.9656   →  完全崩坏
```

**0.315 与 0.966 之间,图像从"几乎一样"跳到"彻底毁掉"。** 像素相对误差对扩散模型没有
分辨力 —— 采样器是混沌的,权重的小扰动会让轨迹分叉,产出一张**像素上完全不同、但视觉
上完全合理**的图。

这否证了本次会话前面若干分析所用的判据:

| 之前用的判据 | 实测 | 有效性 |
|---|---|---|
| 权重重建误差 5.7× | 2bit 0.534 vs 4bit 0.093 | **不能预测图像质量** |
| 单层放大率 A | 跨 1e-20…1.0(退化) | 无效 |
| 整塔输出 rel err | 未测成(字段取错) | 无效 |
| 模型级输出 rel err(SD15 UNet 前向) | 4bit 0.0292 vs 2bit 0.1393(4.77×) | **方向对,但无法判定"能不能用"** |
| **端到端出图** | **4bit 可用 / 2bit 崩坏** | **有效** |

**教训:对生成模型,"数值误差"不能替代"看输出"。** 这一条值得写进报告。

## 测量范围(必须随结论一起说)

| | |
|---|---|
| 量化对象 | UNet 的 **184 个 Linear 层 = 1.13e9 总参数的 31.4%** |
| **未量化** | UNet 的 **68.5% Conv2d**(bnb 不支持卷积量化)、VAE、text encoder |
| 采样器 | DDIM,20 步,guidance 7.5,384×384,seed 1234 |

**所以严格说:本实验测的是"UNet 的注意力投影在 2bit 下会崩"。** 由于只动了 31.4% 的
参数就已经崩到纯噪声,把剩下的卷积也量化只会更糟,不会更好 —— 但这个推论是推理,不是
测量,按本项目惯例标明。
