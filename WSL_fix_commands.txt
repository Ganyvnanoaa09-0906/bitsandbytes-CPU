================================================================================
WSL 修复步骤（本机 R5 无管理员权限，无法代执行——请在【管理员 PowerShell】运行）
================================================================================

【背景】WSL 报「WSL2 无法启动，因为此计算机上未启用虚拟化」
  · CPU 虚拟化(BIOS VT-x) 已开启(VirtualizationFirmwareEnabled=True) —— 已确认 OK
  · 缺的是 Windows 功能「虚拟机平台 VirtualMachinePlatform」+「适用于 Linux 的子系统」
  · 且未安装任何 Linux 发行版(distro)
  · 之前 HCS_E_SERVICE_NOT_AVAILABLE 就是这个根因

----------------------------------------------------------------------------
步骤 ① 以【管理员身份】打开 PowerShell（开始菜单搜 PowerShell → 右键管理员）
----------------------------------------------------------------------------
然后逐个粘贴执行（每个若提示已完成/已启用即可）：

    Set-WindowsOptionalFeature -Online -FeatureName "Microsoft-Windows-Subsystem-Linux" -All -NoRestart
    Set-WindowsOptionalFeature -Online -FeatureName "VirtualMachinePlatform" -All -NoRestart

    状态检查（确认变成 Enabled / EnabledPending）：
    Get-WindowsOptionalFeature -Online -FeatureName "VirtualMachinePlatform" | Select-Object FeatureName,State
    Get-WindowsOptionalFeature -Online -FeatureName "Microsoft-Windows-Subsystem-Linux" | Select-Object FeatureName,State

----------------------------------------------------------------------------
步骤 ② 重启计算机（必须，让虚拟化功能生效）
----------------------------------------------------------------------------

----------------------------------------------------------------------------
步骤 ③ 重启后，【普通 PowerShell】安装 Ubuntu（WSL2 默认）
----------------------------------------------------------------------------
    wsl --install -d Ubuntu

    （若自动失败/超时，可用：
      wsl --set-default-version 2
      wsl --list --online
      wsl --install -d Ubuntu-24.04
    ）

----------------------------------------------------------------------------
步骤 ④ 启动 Ubuntu 并初始化（首次会让你设用户名/密码）
----------------------------------------------------------------------------
    wsl -d Ubuntu

    进入后验证：
    uname -a                # 应显示 Linux x86_64
    sudo apt update && sudo apt install -y g++ libomp-dev python3 python3-venv

----------------------------------------------------------------------------
步骤 ⑤ 回到仓库验证 Linux 编译 + 自检
----------------------------------------------------------------------------
    cd /mnt/<你拷贝的盘符>/那很有乐子了~/bitsandbytes   # 例 cd /mnt/e/那很有乐子了~/bitsandbytes
    bash wsl_verify.sh             # 全链路（编译+C层自检+装torch+gdns selftest+8bit冒烟）
    bash wsl_verify.sh --no-torch  # 快速版（跳过 torch，只到 C 层自检）

    看到最后一行 "WSL 验证完成。若以上全部 OK，则 Linux 支持(x86_64/AVX2)已验证"
    即 Linux 支持验证通过。

【注意】
  · 步骤①必须管理员；步骤②重启；步骤③④⑤普通 PowerShell/终端即可。
  · 若步骤①的 Set-WindowsOptionalFeature 报错，检查是否真是管理员窗口，
    或先运行：Enable-WindowsOptionalFeature -Online -FeatureName "VirtualMachinePlatform" -All
